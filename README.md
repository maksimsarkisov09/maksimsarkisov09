## Current project: TechFlip

TechFlip is a local app for comparing used computer hardware listings and organizing potential deals.

- Compare asking prices with approximate offline resale estimates.
- Save and filter listings, track changes, and keep personal notes.
- Adjust pricing assumptions and retain manual corrections.

**Built with:** Python, Streamlit, and SQLite.

**Status:** In active development, with a focus on personal usefulness, clear interfaces, and reliability.
